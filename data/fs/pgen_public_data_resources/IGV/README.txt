IGV genome definitions.

In IGV: Genomes > Load Genome from File... and choose
  /public_data_resources/IGV/hg38/hg38_local.json    (GRCh38)
  /public_data_resources/IGV/hg19/hg19_local.json    (GRCh37)

The genome box of IGV's toolbar lists them too, once loaded.

[Training simulator: these definitions point at the genome files the IGV team
hosts online. The example genomes of the simulator's /genomes folder are aligned
to two windows of GRCh38 chromosome 21: choose "GRCh38 chr21 windows (training)"
in the genome box (it is /pgen_public_data_resources/reference_genomes/
demo_chr21_windows/reference.fa) to view them.]
